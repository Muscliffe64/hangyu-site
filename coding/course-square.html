课程广场Course Square

《人工智能导论》的班级社区，八十个学生。三个栏目：下节课想听什么、作品与分享、课程资料。首页一行就能发帖；勾上“只给老师看”，就是一张实名的课后小票。给想听的话题点赞就是投票，票数最高的那一条，下节课一定讲。

A class community for Introduction to AI, with 80 students. Students vote on what the next class should cover, and the top topic always gets taught.

它怎么用How it works

  1. 提一个问题可以匿名。匿名只对同学隐藏，老师能看到，发帖时写得清清楚楚。
  2. 投票给想听的话题点赞。开课前的票算这一讲，开课后转向下一讲。
  3. 排进第 N 讲我把问题排进某一讲，提问的同学会收到通知；讲完自动变成“✓ 第 3 讲讲过”。
  4. 不漏掉一条“待回应”页列出我还没回的帖子和留言，有新的会推到我手机上。

为什么做Why I made it

《人工智能导论》是全校公选课，八十个学生来自各个专业，谁都不认识谁，建个微信群也不会有人说话。所以我在备第一节课的时候，花不到两个小时搭了这个广场：可以匿名说话，也有一个板块专门让大家写自己想听什么。我每周去看大家想听什么，再去找相关的内容来讲。

一对八十的课怎么做到个性化？我的回答之一是：每一讲的内容都整理好放上来，学生可以下载下来，交给自己的 AI，说“今天老师讲的这一段我没听懂，用初中生能理解的方式再给我讲一遍”。

这个广场的内容理论上来说，你可以复刻到任何一门课里头，所以其实这是大家共同可以去创作的。……你可以把你 GitHub 的用户名粘贴到这个课程广场上，我到时候把你加进去，然后我们可以一同开发这个平台。

人工智能导论课堂录音 · 2026.09.20

有个学生写了一份很认真的体验报告给我：一打开就是空白编辑框，学生不知道写什么，懒得开始；点了赞也没有反馈。这两点提得特别好，因为他就是这个用户。后来首页改成了一行就能发帖。

它还没解决的难题，我也想写在这里：绝大多数同学的学习主动性，和 AI 结合得还不是很好。
